# 智变 · AI 新质生产力观察站（最终上线版）

最终网站：https://ai-productivity-observatory-20261004.s2336789.chatgpt.site/

本地入口：双击根目录 `index.html`，或直接打开 `website/dist/index.html`。网站使用原生 HTML、CSS、JavaScript 和 SVG，无需安装依赖；访问论文与报告原文需要联网。

## 最终交付文件

- `website/`：与最终上线版本一致的网站源码、静态资源、发布配置和 Git 记录。
- `二号项目-最终版源码.zip`：网站源码、数据、说明文档及视频重制素材；成片单独提供。
- `website-deployment-final.tar.gz`：最终网站发布包。
- `智变-网站交互演示-沉稳男声-双语字幕.mp4`：约 2 分 36 秒的交互导览，中文沉稳男声、自然语速、中英双语字幕。
- `智变-中英双语字幕.srt`：独立双语字幕。
- `data/`：采用率与效率研究的原始数据快照。
- `docs/`：项目说明、发布指南、演示讲稿、最终验证记录和图表截图。
- `video/`：最终讲稿、14 段配音、482 张有效操作画面、制作记录和重制脚本。

## 最终网站功能

顶部可随时切换中英双语及深浅主题。六章内容包括全景观察、效率证据、五产业案例、人机协同实验室、机遇与边界、数据与方法；论文与报告均有直接来源链接。

采用率图包含 2025 年的 88%，近期纵轴为 50%–90%，全部年份为 20%–90%，均注明非零起点。悬停年份点直接显示对应百分比，样式与末尾 88% 一致；88% 始终可见。左下角显示“2026版报告”。网页不含 CSV 导出按钮。

数据是固定研究快照，实验室是教学模拟；2026 是项目版本，不改变原始论文和报告的发表年份。详细口径见 `docs/项目说明.md`。

## 使用与维护

可选 HTTP 预览：在 `website` 目录运行 `node preview.mjs`，访问 http://127.0.0.1:4173/ 。发布方式及现有线上信息见 `docs/发布指南.md`。

视频演示整页滚动、主题与语言切换、图表悬停、产业选择，以及实验室滑块、情景按钮和计算方法。重制步骤见 `video/README.md`。临时运行库与编码文件已清理，所需依赖列在 `video/requirements.txt`。

运行 `python video/package_final.py` 可核对有效素材并重新生成最终源码包。

GitHub 仓库首页说明：[README 模板](docs/GitHub/README.md)，适用于将 website/dist 内的网页文件直接上传到仓库根目录。
